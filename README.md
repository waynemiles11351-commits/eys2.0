# GGD Identity Overlay v3

Target: com.seayoo.ggd 1.1.13 arm64 iOS 18+

This version prioritizes stability. The dylib constructor installs only a small UIKit overlay and does not touch Unity/IL2CPP. Runtime probing is started manually from the panel after the game is fully loaded.

Build via GitHub Actions. Artifact: GGDIdentityOverlay-v3-arm64.
